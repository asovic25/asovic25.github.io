## Files
- `index.html` — portfolio content
- `style.css` — responsive styling
- `script.js` — small mobile-menu/year script

## Publish with GitHub Pages

Your existing GitHub repository is intended to be:

`https://github.com/asovic25/asovic25.github.io`

1. Open the repository on GitHub.
2. Upload/replace `index.html`, `style.css`, and `script.js` in the repository root.
3. Commit the changes.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. Your portfolio should become available at:
   `https://asovic25.github.io/`
